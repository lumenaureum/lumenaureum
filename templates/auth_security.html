Unattended unlock

Off by default. When on, Lumen Aureum unlocks itself after a restart using a key file kept on a separate volume (CRM_UNLOCK_KEY_FILE). Anyone who has both that volume and the data can read everything, so keep the file somewhere a thief would not also take, such as an encrypted dataset that is locked when the machine is off.
